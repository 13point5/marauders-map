# User-supplied Marauder’s Map references

All ten original HEIC photographs are preserved, unmodified, in `originals/`.
The initial set is IMG_5430–IMG_5433; the additional set is IMG_5440–IMG_5445.
`manifest.json` records byte lengths and SHA-256 checksums against the supplied originals.
`previews/` contains oriented JPEG previews for browsing directly in the repository.
These are authoring references and are not served by the website.

## Expanded references and proposals

`expanded/Photo-1.jpg` and `expanded/Photo-2.jpg` preserve the two subsequent JPG attachments. The first appears to be a repeating decorative composition; the second shows the long map with the central cover strip visible. `expanded/crops/` contains enlarged inspection crops, not additional source detail.

`proposals/` preserves the wide concept and four-stage unfolding storyboard. Those are AI-generated planning images, not a record of the original prop’s exact folding mechanics. `proposals/implemented-art-prompts.txt` records the two built-in image-generation prompts for the cover and map now used in `public/art/`.
